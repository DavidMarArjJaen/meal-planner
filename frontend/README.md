# Frontend

Interfaz React para gestionar el catálogo de platos, los planes semanales y la lista de la compra.

Desde esta carpeta:

```bash
npm install
npm run dev
```

La interfaz necesita la API FastAPI activa en `http://127.0.0.1:8000`. Ejecuta `npm run lint` y `npm run build` para validar los cambios.
